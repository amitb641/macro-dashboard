HOW IT WORKS

cadence: weekly Fri 06:00 UTC + monthly 2nd Sat  ·  output: single-file HTML, ~539 KB  ·  runtime: GitHub Actions

Eleven-stage Python pipeline. Pulls from FRED, BLS, EIA, UMich, and quarterly earnings transcripts; scores divergences against a curated baseline; renders a single-file HTML briefing; gates publication on a ten-pass validator. Four agents call Claude (commentary, vision review, earnings extraction, repair diagnosis); seven are deterministic. Every LLM call is bounded by a kill-switch, cost cap, path allowlist, and append-only audit log.

Every call passes through bounded_llm_call() which enforces the four-layer guardrail before the request leaves the process:

# scripts/_agent_guardrails.py — semantics
def bounded_llm_call(agent, prompt, *, model, write_path=None):
    if env("AGENT_DISABLE_ALL") == "1": raise KillSwitch
    if calls_this_run >= env_int("AGENT_MAX_LLM_CALLS"): raise CostCap
    if write_path and write_path not in ALLOWLIST[agent]: raise PathDenied
    response = anthropic.messages.create(model=model, ...)
    append_jsonl("data/agent_memory.jsonl", audit_entry(...))   # rolling cap 2000
    return response
