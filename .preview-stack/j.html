How the Macro Dashboard works.

A multi-agent system of eleven specialised programs pulls macro data from five public sources, computes the indicators, drafts commentary, and gates publication through layered cross-checks. Each agent has a single responsibility; each agent's output is verified by another before the briefing ships.
