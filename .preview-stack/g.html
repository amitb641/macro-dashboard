How the Macro Dashboard works

The macro dashboard is an automated system that retrieves U.S. macroeconomic data from five public sources, computes a set of indicators, and publishes a single-page briefing on a weekly schedule. Indicator values are computed by deterministic code from the source observations. Written commentary on each indicator is drafted by an Anthropic Claude language model under documented constraints. The system runs on a scheduled job; no manual step is required between scheduled runs.

Use of artificial intelligence

where AI is and is not used

AI is used in four of eleven production stages. None of these stages compute or alter any published numeric value. Their outputs are limited to written commentary, classification of validation findings, and image-based quality review.

Stage 03 · Commentary
Per-indicator written commentary

Drafts 2–4 sentences per panel. Sentence count, vocabulary, and factual grounding rules are enforced after generation.

Stage 07 · Visual review
Image-based chart review

Reviews rendered charts against the visual specification. Output is a flag for editorial review, never an edit.

Stage 09 · Earnings extraction
Field extraction from transcripts

Extracts pre-defined fields from archived bank transcripts. All cited quotes are verified verbatim against the transcript.

Stage 10 · Diagnostic review
Finding classification

Reads validation findings and recurrence history; classifies each finding as first-time or recurring for the editor's queue.

Operational controls on AI use

four controls, applied to every AI call
Circuit breaker

A single configuration flag stops all AI calls system-wide.

Cost ceiling

Per-run call count is capped; production does not exceed the configured budget.

Path restriction

Each AI stage may only write to a specifically permitted file. Indicator values and layout files are not on the list.

Audit trail

Every AI call records its prompt hash, model, token count, and output destination to an append-only log.
