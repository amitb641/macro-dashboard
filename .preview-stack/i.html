How the Macro Dashboard works

A multi-agent system of eleven specialised programs that pull macro data from five public sources, compute the indicators, draft commentary, and gate publication through layered cross-checks. Each agent has a single responsibility; each agent's output is verified by another before the briefing ships — a defense-in-depth design intended to keep accuracy and reliability high.

How accuracy & reliability are maintained

defense-in-depth · multiple independent checks before publication
Why multi-agent

No single agent decides what ships. Eleven specialised programs each do one thing, and each one's output is verified by at least one other agent before publication.

AI is bounded by deterministic gates downstream. If an AI step drafts a number that doesn't match its underlying source, the Validator (a deterministic agent) blocks the send.

The Vision Review agent — an independent multimodal AI — looks at the rendered charts and flags issues the DOM-based Visual QA agent cannot see. Two agents, two independent perspectives.

L1
Source verification
Every API endpoint and AI model ID is verified before the run begins.
enforced by Agent 00 · Preflight
L2
Numerical reconciliation
Every value shown on the page must trace back to a raw observation from a named source. Cross-source agreement checked between FRED and BLS.
enforced by Agent 06 · Validator (C-01, C-02, C-08)
L3
Earnings-quote verbatim
Every quoted bank-commentary span must exist verbatim in the archived transcript. No paraphrase passes.
enforced by Agent 06 · Validator (C-04)
L4
Visual verification (two agents)
DOM-based check (224 deterministic rules) + an independent image-based AI review of the rendered charts.
enforced by Agents 07 & 08 (independent)
L5
Recurrence diagnostic
Validation findings are classified against the run history; recurring issues are surfaced for the editor.
enforced by Agent 10 · Repair
L6
Publication gate
The publisher reads a single aggregated verdict (PASS / WARN / FAIL). Any critical divergence → no send.
enforced by Agent 05 · Publisher
