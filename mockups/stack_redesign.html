Why multi-agent? Only Agents 3, 8, 9 use an LLM — everything else is pure Python with no AI cost. Each agent is independently testable and independently failable. The self-verification stack (Agent 0 + Pass 3f/3g/3h + Agent 10) was added in May 2026 after a six-bug audit found the same failure class shipping repeatedly: rebuilds silently failing → static seeds rendered as fresh. The architecture is now designed so that class can never recur — every external dependency is pre-flight validated, every renderer key has a static-analyzed contract with the collector, and every static seed is recomputed each run.
